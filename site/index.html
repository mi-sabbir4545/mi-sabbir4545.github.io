About

Tester by trade, attacker by mindset

I'm a QA Automation Engineer with nearly six years of manual and automated testing of web, mobile (Android & iOS) and API products for HRMS, fintech, healthcare, EdTech, e-commerce, logistics and transport companies. I've built a UI automation framework from scratch, set up QA processes for product teams, and reviewed 110+ third-party apps for the Mailchimp Partner Program.

Alongside automation I do hands-on security testing: SQL injection, XSS, IDOR / broken access control and JWT / session flaws with Burp Suite, OWASP ZAP, Nmap and Kali Linux. I also bring AI into everyday testing with Claude Code.

            What kind of testing does Moinul Islam do?

            Manual and exploratory testing, web, mobile (Android & iOS) and API test automation, performance testing, and hands-on security testing. He has nearly six years of experience, starting in 2021.

            Which test automation tools does he use?

            Selenium (Java and Python), Playwright, Cypress, Appium and Robot Framework for UI and mobile; Postman/Newman, Rest Assured and Karate DSL for APIs; k6, JMeter and Gatling for load testing; Jenkins and GitHub Actions for CI.

            Does he do security and penetration testing?

            Yes. He tests for SQL injection, XSS, IDOR / broken access control and JWT and session flaws with Burp Suite, OWASP ZAP, Nmap and Kali Linux, against the OWASP Top 10 and OWASP API Security Top 10, and is working towards the eJPT certification.

            Which industries has he tested for?

            HRMS and payroll, fintech, healthcare, EdTech, e-commerce and payment gateways, logistics, transport systems, warehouse and procurement, supply chain, email-marketing SaaS and digital advertising.
